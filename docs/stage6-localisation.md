# المرحلة السادسة: صفحات اللغات المستقلة

- العربية: المسارات الحالية في الجذر؛ الهولندية: /nl/ مع نفس أسماء الصفحات ومجلد /nl/articles/.
- 38 زوجاً: الصفحة الرئيسية وفهرس المقالات ومن نحن وسياسة المحتوى والخصوصية والتواصل والأدوات وCV، مع 30 مقالاً من المرحلة السابقة.
- لكل صفحة lang وdir وعنوان ووصف وcanonical ذاتي وOpen Graph مستقل. hreflang ar وnl وx-default متبادل ومطلق في head. اختيار x-default هو الصفحة العربية المقابلة.
- زر اللغة رابط إلى الصفحة المقابلة، متاح دون JavaScript. لا يغيّر localStorage أو ?lang= محتوى الصفحة نفسها. JavaScript يظل ضرورياً لحسابات الأدوات وإنشاء CV والبحث التفاعلي؛ النصوص الأساسية ثابتة.
- لم تُترجم مقالات جديدة آلياً في هذه المرحلة. فُصلت النصوص الهولندية الموجودة، وراجعت الصياغة والمصطلحات والتناسق والروابط بواسطة المساعد. لا توجد مراجعة مترجم بشري مستقل أو متخصص قانوني/ضريبي؛ يظل بيان المساعدة بالذكاء الاصطناعي وحدود المراجعة في المقالات والسياسة.
- الثمانية القديمة لا تُعرض في الفهرس الهولندي ولا تحمل hreflang زائفاً. تُضاف مقابلتها بعد مراجعة المحتوى والترجمة.
- nl.html يصبح صفحة انتقال للعنوان الجديد مع canonical إليه. لا توجد إعادة توجيه بحسب بلد الزائر أو لغة المتصفح.
- خريطة الموقع تشمل جميع النسخ الجديدة. نستخدم hreflang في HTML وحده، فلا نكرره في XML بلا حاجة.
- ملفات CSS وJS والأدوات مشتركة من /assets/؛ لا يكرر مجلد nl الملفات البرمجية. تحديث cache إلى v31.

## التحرير لاحقاً

1. عدّل الصفحة العربية والصفحة المقابلة في nl معاً عندما تتغير المعلومة.
2. راجع الترجمة الهولندية خصوصاً المصطلحات والأرقام والمواعيد. لا تضف تاريخ تحقق جديداً إن لم تُراجع المصدر.
3. أضف الصفحة إلى docs/language-pairs.json فقط عند وجود مقابلتها الفعلية.
4. تحقق من hreflang المتبادل وcanonical الذاتي والروابط المحلية ثم أضف النسخة الجديدة إلى sitemap.xml.
5. راقب الفهرسة في Google Search Console؛ تنفيذ hreflang لا يضمن الفهرسة أو ترتيباً معيناً أو قبول AdSense.

مرجع التنفيذ: https://developers.google.com/search/docs/specialty/international/localized-versions

## التحقق

فحص محلي لكل زوج: اللغة والاتجاه، canonical وhreflang، روابط اللغة والأصول والأقسام، Schema Article، عدم وجود نص عربي في المحتوى الهولندي سوى رابط العربية، وخريطة الموقع. فُحص أن اللغة المحفوظة المخالفة وquery لا يبدلان لغة الرابط، وأن البحث يعمل وأن CV يبدأ فارغاً. لم يُجرَ اختبار بصري على هاتف فعلي أو قياس Core Web Vitals، ولا يمكن تأكيد الفهرسة قبل معالجة Google للموقع.
