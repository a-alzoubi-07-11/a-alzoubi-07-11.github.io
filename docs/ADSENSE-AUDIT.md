# تدقيق 1 أكتوبر 2026 — الدفعة الأولى

## حرج
- النظام المحلي السابق ليس CMP معتمدة، ولا يرسل Consent Mode v2. وحدات الإعلانات كانت متوقفة؛ لم نثبت عرضاً مخالفاً. الحل: default denied، حفظ آمن، واجهة AR/NL، إبقاء طلب الوحدات متوقفاً حتى إعداد Google CMP.
- الأرقام المتغيرة تحتاج مصادر وسنة وحدود استخدام. جداول تعليمية في الرئيسية تحتاج مراجعة قبل اعتماد الصفحة إعلانياً. بيانات الحاسبات الجديدة غير المتحقق منها بقيت null، فلا تنتج تقديرات مخترعة.

## عالٍ
- المقالات الثلاثون قصيرة: نحو 337–457 كلمة للصفحة العربية بما فيها التنقل. يحتاج كل مقال توسعة عملية أصلية ومراجعة مصادر. 1200 كلمة هدف تحرير طلبه صاحب الموقع، وليس شرط قبول رسمي من Google.
- المقالات القديمة الثمانية تحتاج تدقيقاً منفصلاً؛ لا ننشئ تاريخ نشر أو مؤهلات للمؤلف دون دليل.
- النسخ العربية والهولندية لها 38 زوجاً من روابط اللغة. ليست تكراراً يستوجب دمج اللغتين. يحتاج الفرق التحريري والتوافق اللغوي مراجعة بشرية.
- صفحة 404 كانت مفقودة. أُضيفت صفحة حقيقية noindex.
- أدوات الراتب والإعانات ليست صفحات مستقلة بعد. الحاسبات الخمس وشرحها وFAQ ومصادرها دفعة لاحقة.
- Meta descriptions في بعض صفحات السياسات قصيرة. توحيد جميع العناوين والوصف وبيانات Article/Breadcrumb/OG/FAQ مع المحتوى الفعلي ما زال مطلوباً.

## متوسط
- سكربت الرئيسية نحو 407KB وCSS الرئيسية نحو 86KB؛ يلزم تحليل اعتماديات قبل فصل الكود. لم تُقَس LCP/CLS/INP ميدانياً، فلا توجد نتيجة نجاح معلنة.
- صورة OG نحو 92KB. أبعاد الصور وLCP والخطوط والتباين وRTL والتنقل بلوحة المفاتيح تحتاج اختباراً بصرياً وأدوات أداء.
- أُضيف تذييل موحد وإعدادات كوكيز، لكن توحيد الترويسة وCSS بالكامل لم يكتمل.
- أُعيد إنشاء sitemap مع بدائل hreflang الحالية. robots يسمح بالفهرسة؛ صفحات المنفعة تستخدم noindex بدلاً من منع Google من قراءة التوجيه.
- لم نثبت أن جميع الروابط الخارجية تعمل. المراجعة الكاملة والروابط الداخلية والمراكز الموضوعية تحتاج دفعة لاحقة.

## تنفيذ الدفعة الأولى
أُضيف consent default قبل سكربت AdSense مرة واحدة في head لكل HTML. حساب الناشر وads.txt صحيحان. لا وحدات إعلانية مفعّلة، ولا Auto Ads نفعّلها برمجياً. local banner لا يحل محل TCF. GA4 placeholder متوقف. ملفات shared كاملة ضمن هذه الحزمة؛ CSS الجديد طبقة مشتركة إضافية تحافظ على التصميم القائم، لا إعادة بناء.
حاسبة الراتب الحالية تعتمد rates.json؛ فشل التحميل أو انتهاء السنة يوقف الحساب. حقول أسعار الأدوات الأربع الأخرى غير المتحققة null.

## الخطوات اليدوية
1. AdSense > Privacy & messaging > European regulations: إنشاء رسالة للموقع، تفعيل اختيار عدم الموافقة وإدارة الخيارات، العربية والهولندية، رابط الخصوصية، ثم النشر. فعّل دعم Consent Mode للإعلانات والإحصاءات حسب إعدادات Google الحالية.
2. اختبر الرسالة في نافذة خاصة عبر ?fc=alwaysshow&fctype=gdpr. تأكد من TCF والتحديث الفعلي عند القبول والرفض والسحب. لا تغيّر cmpReady إلى true قبل الاختبار.
3. أبق Auto Ads متوقفة حتى مراجعة مواضعها. أدخل أرقام الوحدات الحقيقية بعد توسعة المحتوى؛ YOUR_SLOT_ID ليست أرقاماً صالحة. لا تضع وحدات في CV أو السياسات أو التواصل أو 404.
4. الإعلانات المسموحة لاحقاً: الرئيسية وفهرس المقالات حتى وحدتين؛ المقال المفصل ثلاث؛ الحاسبة تحت النتيجة حتى اثنتين. احتفظ بمسافة 40px عن عناصر التفاعل وارتفاع محجوز. هذه حدود صاحب الموقع وليست ادعاءً بقاعدة Google ذات عدد ثابت.
5. GA4: استبدل G-YOUR_MEASUREMENT_ID فقط إذا رغبت بالإحصاءات، واختبر أن الرفض يمنع التحميل. لا يعتبر Consent Mode موافقة قانونية بمفرده.
6. Search Console: افتح ملكية https://gidsnederland.nl/، Sitemaps، أدخل sitemap.xml. افحص الرئيسية وفهرس المقالات وخمس صفحات مهمة عبر URL inspection وRequest indexing. راجع Page indexing وCore Web Vitals بعد توفر البيانات.
7. الربط: يمكن ربط Search Console مع GA4، وربط AdSense مع GA4 إذا ظهر الخيار لحسابك؛ لم نتحقق من ربط مباشر بين Search Console وAdSense، فلا يوجد زر نفترضه.
8. اطلب مراجعة AdSense بعد اكتمال المحتوى والإعدادات ونشرها واختبارها؛ لا ضمان قبول.
