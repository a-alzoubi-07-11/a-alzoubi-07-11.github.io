# بوت فهرس البحث

يعمل البوت تلقائياً من GitHub Actions (`Search index bot`):

- **متى؟** عند كل تعديل HTML يُدفع إلى `main` أو تعديل مولّد الفهرس، ومرة يومياً، أو يدوياً من Actions → Search index bot → Run workflow.
- **ماذا يفعل؟** يشغّل `.github/scripts/build_search_index.py`، فيقرأ كل المقالات (العنوان والوصف والعناوين الفرعية)، ويعرف قسم المقال من صفحات الأقسام التي تربط إليه، ثم يكتب `assets/search-index.json` وينشره إن تغيّر.
- **مقال جديد؟** يكفي أن يكون الملف في `articles/` وأن تضيف رابطه في صفحة القسم المناسبة. البوت يضيفه للبحث بكلمات مفتاحية تلقائية (العنوان، المصطلحات الهولندية، كلمات الرابط).
- **لتحسين البحث بالعامية** أضف للمقال كلمات بديلة في `ALIASES` داخل السكربت (مثل: «فلوس الاولاد» لـ Kinderbijslag). تقرير البوت في صفحة التشغيل يذكر المقالات التي ما زالت تعتمد على الكلمات التلقائية فقط، والمقالات غير المربوطة بأي قسم.
- **الصفحات والأدوات خارج المقالات:** تجمع قائمة `SITE_PAGES` الرئيسية، وصفحتي المقالات والأدوات، وأداة الطعن، ومن نحن، والتواصل، وسياسات المحتوى والخصوصية والإفصاح الإعلاني، بالعربية والهولندية. تُقرأ عناوينها وأوصافها من ملفات HTML، وتُضاف كلمات بحث عربية وهولندية. أضف أي صفحة عامة جديدة إلى هذه القائمة ليحتفظ بها كل تحديث للفهرس.
- **نطاق العمل:** هذا فهرس البحث الداخلي فقط؛ لا يغيّر إعدادات فهرسة Google أو محتوى أداة الطعن.
