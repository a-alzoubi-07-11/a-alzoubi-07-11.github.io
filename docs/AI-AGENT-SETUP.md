# وكلاء فحص الموقع الحالي

يعمل وكيل الروابط والكود ووكيل SEO من مستودع
`a-alzoubi-07-11.github.io`، من دون تغيير `index.html` أو نشر محتوى آلي.
يعرض كل تشغيل تقريرين في Actions → Artifacts. ويحفظ التشغيل اليومي على
`main` التقارير أيضاً تحت `reports/` في مستودع الموقع الرئيسي.

## النطاق

- عند الدفع إلى أي فرع يحمل ملف workflow، يُفحص HTML في ذلك الفرع وتُحفظ تقاريره كملفات تشغيل.
- يومياً الساعة 08:00 UTC من `main`، يُفحص الموقع الرئيسي والروابط الموجودة في sitemap
  وصفحته الرئيسية؛ تُكتشف أيضاً مستودعات GitHub Pages العامة الأخرى التابعة للحساب
  من GitHub API وتُفحص صفحاتها المنشورة. لا يفحص ذلك نسخة غير منشورة من فرع في مستودع آخر.
- يعمل مستودع الرابط الطويل من خلال workflow صغير يستدعي الوكلاء الموجودين في مستودع
  الرابط القصير. ستَرث الفروع الجديدة المنطلقة منه هذا التشغيل.
- للمستودعات الجديدة مستقبلاً، أضف workflow المستدعي أو أنشئها من قالب يضمّه؛
  سيُكتشف عنوان GitHub Pages العام في التدقيق اليومي بعد تفعيل Pages.
  المواقع الخاصة أو النطاقات الخارجية غير المرتبطة بالموقع تحتاج إعداداً صريحاً.

## تشغيل وتخصيص

من تبويب Actions اختر `Site code and SEO agents` ثم `Run workflow`.
يمكن إضافة `AI_API_KEY` إلى Secrets لتوصيات النموذج الاختيارية على `main` فقط،
وضبط `AI_API_BASE` و`AI_MODEL` في Variables عند استخدام مزود متوافق.
التقارير التقنية تعمل بلا مفتاح. GitHub Actions لا يشغّل الجدولة إلا من الفرع الافتراضي.

الاقتراحات تقارير للمراجعة البشرية؛ لا يصلح الوكيل الكود تلقائياً ولا يضمن ترتيب
البحث أو قبول AdSense. روبوت المحادثة التجريبي في صفحة فرع Bionic يتطلب خدمة
منفصلة، ولذلك لم يُنقل إلى واجهة الموقع.
